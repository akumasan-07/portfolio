# Personal Portfolio Website

A modern and responsive portfolio website built to showcase my projects, skills, and contact information.

## Tech Stack

* React
* Vite
* Tailwind CSS
* Framer Motion
* EmailJS

## Features

* Responsive design
* Smooth animations with Framer Motion
* Skills marquee section
* Project showcase
* Contact form with EmailJS integration
* Mobile-friendly navigation

## Live Demo

[Portfolio Website](https://portfolio-nine-umber-23.vercel.app/)

## Run Locally

```bash
git clone <repository-url>
cd <repository-name>
npm install
npm run dev
```
